# Logos

## Danone (sidebar)

Pasta **`logo danone/`** na raiz do projeto.

O menu lateral usa o primeiro arquivo encontrado, nesta ordem de preferência: versão branca/clara, depois qualquer `.png` / `.jpg` na pasta.

## ABRAFAD (topo da página)

Pasta **`logo Abrafad/`** na raiz do projeto.

O dashboard usa automaticamente `Logo ABRAFAD - Branco.png` (fundo preto, como no arquivo original).
